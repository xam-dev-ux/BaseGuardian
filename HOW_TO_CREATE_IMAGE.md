# Cómo Crear la Imagen para Twitter

## 🎨 Tienes 2 diseños disponibles:

1. **twitter_image.html** - Diseño profesional con características detalladas
2. **twitter_image_simple.html** - Diseño minimalista con foco en el mensaje clave

## 📸 Método 1: Captura de Pantalla (Más fácil)

### Pasos:

1. **Abre el archivo HTML en tu navegador:**
   ```bash
   # En Linux:
   xdg-open twitter_image.html

   # O arrastra el archivo a tu navegador
   ```

2. **Ajusta el zoom al 100%** (Ctrl+0 o Cmd+0)

3. **Presiona F11** para pantalla completa

4. **Captura la pantalla:**
   - Windows: `Windows + Shift + S`
   - Mac: `Cmd + Shift + 4`
   - Linux: `PrintScreen` o usa la herramienta de captura

5. **Recorta** solo la tarjeta blanca/azul central

6. **Guarda como PNG**

**Dimensiones ideales para Twitter:** 1200x630 px (ya está configurado)
